API Oficial do WhatsApp: o que é, quanto custa e como ativar sem perder seu número

A API oficial do WhatsApp é a conexão que a própria Meta criou para empresas usarem o WhatsApp de forma profissional: time inteiro atendendo no mesmo número, envio de mensagens em massa aprovado e automação com IA liberada. Tudo que derruba um número comum, aqui é permitido.

Se sua empresa vende pelo WhatsApp e depende desse número pra faturar, esta página explica o que é a API oficial, quanto custa de verdade e o caminho certo pra ativar sem perder o número e o histórico de conversas.

A escada

WhatsApp comum, WhatsApp Business e API oficial: qual a diferença?

Existem três formas de usar o WhatsApp, e elas não foram feitas pro mesmo tamanho de operação:

WhatsApp comum.

Feito pra pessoa física. Um número, um celular, conversa pessoal. Usar pra vender funciona até certo ponto, mas a Meta trata uso comercial em número pessoal como violação.

WhatsApp Business (o aplicativo verde).

Feito pro pequeno negócio que atende sozinho. Ganha catálogo, etiquetas e mensagem automática simples. Continua preso a um celular e um atendente por número.

API oficial do WhatsApp.

Feita pra empresa que tem time e volume. Não é um aplicativo, é uma conexão direta com a Meta que se liga a uma plataforma de atendimento. É ela que libera vários atendentes no mesmo número, disparo aprovado, chatbot e IA.

A Meta criou essa escada de propósito: separar conversa pessoal de operação comercial. Empresa que cresce e continua no degrau errado é empresa marcada.

O cenário

O cerco fechou: por que a busca por API oficial explodiu

A Meta está bloqueando números comuns usados de forma comercial. Disparo em massa, robô conectado por gambiarra, atalhos de automação em número pessoal: isso hoje é motivo de banimento. E quando o número cai, cai junto o histórico, os contatos e o canal por onde a empresa fatura.

Não sou eu dizendo. É notícia:

  • Metrópoles: usuários relatam banimentos repentinos de contas pessoais e comerciais, atingindo em cheio pequenos empreendedores que dependem do WhatsApp como canal principal. Entre os alvos, contas conversando com muitos números não salvos, o comportamento típico de quem vende.
  • ND+: nova onda de bloqueios em massa derruba contas sem explicação, e a própria Meta admite que o sistema automático comete equívocos. Ou seja: até quem não fez nada errado pode cair.

O resultado aparece no próprio Google: a busca por "api oficial whatsapp" cresceu mais de 125% no último ano. Não é moda. É empresa correndo pra proteger o número antes de ser a próxima.

Migrar pra API oficial não é upgrade. É tirar o faturamento da zona de risco.

Oficial x não oficial

A API não oficial é mais barata. E é exatamente esse o problema.

Existe um mercado de "API não oficial": ferramentas que se conectam ao seu WhatsApp por trás, simulando o WhatsApp Web. São mais baratas, ativam em minutos e não pedem aprovação de ninguém.

Sendo honesto: funciona. Até o dia que não funciona mais.

A Meta não autoriza essas conexões. Quando detecta, bane o número. Sem aviso, sem recurso, sem devolver o histórico. A economia de alguns reais por mês cobra o preço de uma vez: o número que seus clientes conhecem, morto.

Preço

Quanto custa de verdade (sem enrolação)

A resposta que ninguém te dá na cara: a API oficial não é gratuita. Quem promete API oficial de graça está escondendo o custo em outro lugar ou não é oficial.

Como funciona a cobrança, do jeito simples:

1

Conversa iniciada pelo cliente: sem custo de mensagem.

Quando o cliente te chama, abre uma janela de 24 horas. Dentro dela, sua equipe responde à vontade sem pagar por mensagem.

2

Conversa iniciada pela empresa: paga por mensagem de modelo.

Pra falar primeiro com o cliente (disparo, aviso, cobrança, promoção), você usa modelos aprovados pela Meta. Desde julho de 2025 a cobrança é por mensagem enviada, e o valor muda conforme a categoria: marketing, utilidade ou autenticação.

3

O limite de pagamento da Meta.

Conta nova começa com limite de gasto baixo. Conforme os pagamentos são processados, a Meta libera limites maiores. Quem não conhece essa regra planeja um disparo grande e descobre na hora que a conta trava no meio. Faz parte da implementação certa prever isso antes.

4

A plataforma.

Além da Meta, existe o custo da plataforma que dá tela, funil e gestão pra API (falo dela logo abaixo).

Agora a conta que importa: quanto custa não ter? Um número banido no meio do mês, leads sem resposta fora do horário, time inteiro dividindo um celular. Uma venda recuperada por automação paga o custo do mês. É por isso que empresa que fatura pelo WhatsApp trata a API como investimento, não como despesa.

Os valores por mensagem mudam conforme o país e os ajustes da Meta. Por isso não cravo número aqui: cravo o caminho. A tabela oficial e atualizada está na própria Meta: developers.facebook.com/docs/whatsapp/pricing. Na implementação, eu calculo o custo real pro seu volume antes de você ativar.

Ter a API não basta

A API sozinha é um cano sem torneira

Aqui está o que quase ninguém explica: a API oficial, sozinha, não tem tela. Não tem aplicativo, não tem caixa de entrada, não tem funil. Ela é só a conexão autorizada com a Meta.

Pra sua equipe atender, você precisa ligar essa conexão a uma plataforma: o lugar onde as conversas aparecem, os leads entram no funil, o gestor enxerga a operação e a automação roda.

Empresa que contrata "só a API" descobre isso depois de pagar. Você está descobrindo antes.

Perguntas frequentes

Perguntas frequentes sobre a API oficial

O que é a API oficial do WhatsApp?

É a conexão criada pela Meta para empresas usarem o WhatsApp profissionalmente: vários atendentes no mesmo número, disparos aprovados e automação com IA, sem risco de banimento.

A API oficial do WhatsApp é gratuita?

Não. Existe custo por mensagem de modelo enviada pela empresa e o custo da plataforma de atendimento. Quem promete API oficial gratuita não está falando da API oficial.

Quanto custa a API oficial do WhatsApp?

Depende do volume de mensagens que a empresa envia. Conversas iniciadas pelo cliente não geram custo de mensagem dentro da janela de 24 horas. Mensagens iniciadas pela empresa são cobradas por unidade, na faixa de centavos por mensagem, variando conforme a categoria: utilidade custa poucos centavos, marketing custa mais. Os valores atualizados estão na tabela oficial da Meta.

Qual a diferença entre WhatsApp Business e API oficial?

O WhatsApp Business é um aplicativo pra pequeno negócio com um atendente. A API oficial é uma conexão pra empresas com time e volume: vários atendentes no mesmo número, disparo aprovado e automação liberada.

Vou perder meu número ao migrar pra API oficial?

Não. A migração feita do jeito certo mantém o número atual da empresa. Esse é justamente um dos motivos de migrar: proteger o número.

O que é a API não oficial? Vale a pena?

São ferramentas que se conectam ao WhatsApp sem autorização da Meta, simulando o WhatsApp Web. São mais baratas, mas o número pode ser banido a qualquer momento, sem recurso. Não vale o risco pra quem fatura pelo WhatsApp.

Posso fazer disparo em massa na API oficial?

Sim. É um dos usos previstos. Os envios usam modelos de mensagem aprovados pela Meta, o que elimina o risco de banimento que existe no número comum.

Posso usar chatbot e IA na API oficial?

Sim. Automação e agentes de IA são liberados na API oficial. É o único canal do WhatsApp onde isso é permitido pela Meta.

O que é o limite de pagamento da Meta?

Contas novas começam com um limite de gasto em mensagens. Conforme os pagamentos são processados, a Meta aumenta o limite. Uma implementação bem feita planeja os disparos considerando essa regra.

Preciso de CNPJ pra ter a API oficial?

Sim. A API oficial é para empresas. A ativação passa pela verificação do negócio junto à Meta.

Quanto tempo leva pra ativar a API oficial?

De 48 horas a 14 dias, dependendo do tamanho do projeto. A ativação da conexão em si é rápida. O que define o prazo é o desenho da operação: funil, time, automações e migração do número.

A API oficial funciona com a Kommo?

Sim. A Kommo tem a conexão homologada com a Meta, e é a plataforma que uso pra ligar a API na operação comercial dos meus clientes.
